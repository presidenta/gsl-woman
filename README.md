# GSL Woman — тренинги для женщин

Приложение-напоминание для женского тренинга Ладомира: каждый день — одно задание, три тёплых
напоминания (утро — задание, обед — комплимент и «как успехи», вечер — «что ты сделала»), запись
результата и итог недели кольцом. Обучение постоянное; сейчас расписана его первая часть — 24 недели,
ритм 3 + 3 + 1. В надписях нигде не пишем «полгода», «финал», «выпускной» (владелец, 12.11.2026).

Отдельное приложение по образцу спорта (GoldenFit): свой сайт, свой значок на экране телефона
(«GSL Woman»), свои обновления. Потом встраивается в общий сайт так же, как спорт, — см. «Связь с
«Квантом»» ниже.

Без сборки: чистые модули ES в браузере. Открыл файл — правишь — обновил страницу.

**Вход — аккаунтом «Кванта»** (логин и пароль те же), отдельной ссылкой:
https://presidenta.github.io/gsl-woman/. **Текстов программы в этом репозитории нет** — он открытый, а
программа платная: она лежит на сервере «Кванта» (`server/src/woman/` в planner) и приходит на телефон
только после входа. См. [account](js/account/README.md) и [program](js/program/README.md).

## Как устроено

```
main.js ── каркас, маршруты, перерисовка
  │
  ├── screens/*  ← ctx: { settings, entries, day, lang } — экраны только рисуют
  │      └── entry/entry-sheet.js — общая форма записи
  │
  ├── account/   ← вход аккаунтом «Кванта»; без входа — только экран входа
  ├── program/   ← «что делать в день N»: ритм здесь, тексты — с сервера (source.js)
  ├── progress/  ← считает из записей, ничего не хранит
  ├── journal/   ← записи — единственный источник правды о выполнении
  ├── settings/
  ├── reminders/ ← plan.js считает, local.js показывает
  └── core/      ← store (localStorage с приставкой), dates, i18n, router, dom
```

Правила, на которых держится порядок:

- **Экраны не считают.** Процент, отставание, вид дня — из `progress` и `program`. Поменять формулу —
  один файл, экраны не трогаются.
- **Записи — единственная правда.** Прогресс не хранится отдельно, а считается из записей — не может разойтись.
- **Цвета и размеры — только токены.** В `.css` экранов нет ни одного своего цвета.
- **Текст пользователя — только как текст.** `h()` вставляет строки через textContent, HTML не собирается
  из того, что написала женщина.
- **Всё своё — с приставкой.** Адрес presidenta.github.io общий с «Квантом» и спортом: хранилище —
  `gsl-woman:*`, кэши — `gsl-woman-*`. Чистим только своё.

## Добавить…

- **экран** — папка `js/screens/<имя>/` с `render(view, ctx)`, строка `router.define` в `main.js`,
  при необходимости пункт в `NAV`, `<link>` на его css в `index.html`, затем `npm run files`;
- **надпись** — ключ во все три `js/texts/*.js` (тест сверит, что ключи совпадают);
- **задание или неделю** — на сервере: `server/src/woman/program/ru.js` в planner, то же в `ua.js` и
  `en.js`, проверки и выкладка сервера; приложение не трогается;
- **файл любой** — `npm run files`, иначе он не откроется без интернета (тест напомнит).

## Проверки

```bash
npm test          # даты, ритм программы (на учебной), прогресс, напоминания, тексты, список файлов
npm run files     # пересобрать files.js
npm run icons     # значки из assets/icons/icon.svg (Edge + Pillow)
```

## Выкладка

1. Поднять номер в `version.js`.
2. `npm run files && npm test`.
3. Пуш — сайт на GitHub Pages обновится сам; у женщин новая версия встанет при следующем открытии
   (запись, которую она в этот момент пишет, не потеряется — обновление ждёт закрытия формы).
