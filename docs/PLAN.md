## Правила, которые действуют везде

- Тексты программы — **только положительные слова** (без «не», «нет», «ни», «без»); отрицание переписываем
  **заменой** и оставляем, что на что меняем («Телефон в руке → её глаза»). Исключение — весёлые фразы в шапке задания.
- Автора методики **не называть нигде**. Ведущий — «наставник», без имени.
- Обучение постоянное и идёт **по кругу**: нигде «полгода», «финал», «выпускной»; ступени «Новая Я» / «Новый Я».
- **Пока только русский** (владелец 14.11.2026): украинский и английский не правим — пришлют книгу, по ней
  поменяются задания и фразы, переводы — после. Языки без своего текста получают русский.
- Содержание решает владелец; свои правила и оговорки к заданиям не дописывать.
- Выкладка: сервер — правка в `planner/server`, копия в `game/game-of-sages-full/genesisystem/`, перед пушем игры
  `curl https://game.coreviaflow.com/api/version` → `liveRooms` нули. Приложение — `version.js` +1, `npm run files`,
  `npm test` → **fail 0**, потом пуш (сайт собирается сам).
- **Один разговор за раз.** 14.11.2026 два разговора параллельно выложили две разные «сборки 46» — номер совпал.
