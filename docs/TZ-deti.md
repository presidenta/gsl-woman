# Детский кабинет GSL — ТЗ

Решения владельца 14.11.2026 (наброски — документ Google «детские программы», разговор 14.11). Решённое здесь —
истина; наброски документа, которые сюда не вошли, — только идеи.

## 1. Где и для кого

- **В том же приложении GSL** — третья часть рядом с GSL Woman+ и GSL Man+: «детский кабинет». Свой вид (крупно,
  просто, без денег), свой адрес на сервере.
- **Возраст** — без числа: ребёнок получает вход, когда умеет читать и писать (решает родитель). Кабинет — до
  совершеннолетия. Дата рождения в профиле нужна только для перехода в 18 лет.
- Франшиз, ступеней по возрасту, турниров у ребёнка **нет** — просто кабинет.
- **Договор и деньги — только у родителя.** В детском кабинете нет сумм, кошелька, бонусов, выплат.
  Возможно, кабинет ребёнка будет платным для родителя (небольшие деньги) — решим позже; в данных заложить
  отдельную строку доступа, сейчас она следует доступу GSL родителя.

## 2. Вход ребёнка — только через родителя

- Профиль ребёнка заводит родитель в «Семье» (есть с 42). У профиля — «Дать вход».
- Родитель **сам задаёт пароль** ребёнку (значит, знает его) и может сменить в любой момент.
- Родитель получает ссылку / QR. Ребёнок открывает её **на своём телефоне**, вводит пароль.
- **Новый телефон ребёнка активирует родитель**: в кабинете родителя появляется «Ира входит с нового телефона —
  Подтвердить / Отклонить». До подтверждения кабинет закрыт.
- В кабинете родителя видно всё, что есть в кабинете ребёнка (задачи, навыки, мечты, опыт). Личные записи
  ребёнка (письмо себе) — по решению владельца, по умолчанию видны родителю.
- Второй родитель семьи видит ребёнка так же; кто дал вход — для данных неважно.

## 3. Задачи семьи — в семейном чате

- Мама, папа (и ребёнок) пишут в семейный чат **задачу**: по дому или для всей семьи (помыть посуду, приготовить
  еду, заготовить дрова, подумать, куда поехать отдыхать…). Готовые варианты + своё.
- У задачи — **звёзды**. Владелец 14.11.2026: **любое действие — 1 звезда**; за большое дело (генеральная уборка)
  родитель сам ставит больше — из ряда 1 / 2 / 3 / 5 / 10.
- Любой жмёт «Беру» — на задаче видно имя: взял папа / мама / Ира.
- «Сделано» → автор задачи (или родитель) подтверждает → баллы исполнителю.
- Счёт семьи виден всем: **дети видят, что родители тоже делают**, родители — что дети.
- Это частично снимает отложку «очков» (ТЗ «Пара и семья», раздел 9) — только для задач семьи и навыков
  ребёнка; рейтинги и очки пары по-прежнему отложены.

## 4. Навыки ребёнка — опыт

- В кабинете ребёнка — **большой список навыков** по разделам: кухня (вскипятить воду, зажечь плиту,
  приготовить…), дом (помыть посуду…), руки (шить…), уроки и сверх уроков (изучить новое), спорт и др.
- Ребёнок **сам выбирает** несколько заданий на день.
- Учится вместе с родителем: «Мам, помоги — хочу научиться» → у родителя запрос.
- **Подтверждает родитель**: «Получилось» → ребёнку опыт.
- Навык **подтверждается снова и снова** (повторение): уровни навыка, например «научился → делаю сам → мастер».
- Каталог навыков — черновик готовит Claude, утверждает владелец.

## 4а. Живые игры и «телефон отдыхает» (владелец 14.11.2026)

Главная цель детского кабинета — **снизить зависимость ребёнка от телефона и дать живое общение**: найти друзей,
единомышленников и играть вживую.

- Каталог живых игр — классика двора (классики, резиночка, прятки, салки, вышибалы, «Море волнуется», «Съедобное —
  несъедобное», казаки-разбойники, цепи кованые, ручеёк, штандер…): правила, сколько игроков, где, что развивает.
- «Мои друзья» — ребёнок добавляет друзей; каждая игра с новыми именами пополняет список.
- **«Играем вживую»**: ребёнок выбирает игру и друзей → экран-таймер на весь телефон, экран горит; ушёл из приложения
  (другое приложение, главный экран, выключил экран) — приложение замечает и считает «телефон брали N раз». Звонки
  работают. В конце — «Сыграли 25 минут, телефон отдыхал всю игру» → дело ребёнка, родитель подтверждает → звёзды.
- Сайт телефон **закрыть** не может — только честно посчитать. Закрыть телефон на время игры (закрепление экрана
  Android, звонки остаются) — следующий шаг в Android-приложении.

## 5. Мечты (из набросков, принято в разговоре 14.11)

- «Мои мечты»: ребёнок сам добавляет (категории: творчество, спорт, интеллект, путешествия, подарки + своё),
  «Мечта месяца».
- Родитель отмечает: «Куплено» / «Запланировано» / «Пока позже», может дописать пару слов.
- Подарок **не положен за баллы**: «Родители могут открыть одну из твоих мечт» — решают родители.
- «Мечты нашей семьи» — вид в целях семьи. «Письмо самому себе» — «Когда мне будет 18…», перечитать раз в год.

## 6. Приглашения ребёнка — ПОСЛЕ, по методологии игры

- У ребёнка своя ссылка «Пригласить друга» (QR). Кто пришёл по ней, регистрируется **под кабинет ребёнка**, а кабинет
  ребёнка — это кабинет родителя («прокладка», не активная). В кабинете родителя видно отдельно: лично
  приглашённые ребёнком (сверстники и др.). Все деньги — только у родителя.
- Регистрация по приглашению живёт в игре (Project_Methodology.md §11: код продавца, `?ref=`, `referred_by`
  неизменяем, комиссии). Предложение, чтобы денежную часть не трогать: ссылка ребёнка = **код родителя + метка
  «через ребёнка»**; продавец для денег — родитель, метка — только для показа «пришли через Иру».
  Делать после детского кабинета и только через методологию игры (деньги — согласовать).
- У ребёнка — только достижения («Благодаря тебе присоединились семьи: 3»), никаких денег.

## 7. Переход в 18 лет — позже

- Аккаунт ребёнка настоящий с первого дня, поэтому история, навыки, мечты сохраняются сами. Сценарий
  поздравления и своего договора — когда понадобится.

## 8. Порядок сборок

**Сборка 51 (14.11.2026) — сделано одной выкладкой** (владелец: «собрать, посмотрим, потом поправим»): вход ребёнка
через родителя, детский кабинет (Сегодня · Дела · Навыки · Игры · Мечты), дела семьи в чате со звёздами, навыки с
подтверждением, живые игры и «Играем вживую», мечты со статусами родителя, вкладка «Дети» у родителя. Сервер —
`planner/server/src/kids/`, миграция 026. Проверено на компьютере: свой сервер + два Edge в режиме телефона (мама и
ребёнок). На настоящем телефоне — не проверено.

Осталось:
1. Закрепление экрана на время живой игры — в Android-приложении.
2. Точка на «Мы», когда телефон ребёнка ждёт подтверждения (сейчас видно во вкладке «Дети»).
3. «Письмо самому себе», «Мечты нашей семьи», «Кем я хочу стать» (маршруты — содержание от владельца).
4. Приглашения ребёнка — через методологию игры.
5. Содержание (навыки, игры, ступени) — черновик Claude, ждёт правок владельца.
