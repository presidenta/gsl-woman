# Родная часть (приложение для Android)

Владелец 13.11.2026, шаги 2–4 отдельного APK: напоминания при закрытом приложении, будильник на весь экран как в
«Кванте», виджет на экран телефона. Сама родная часть — `android-app/plugin/` (Java): `GslNativePlugin`
(мост), `GslScheduler` (будильники Android через setAlarmClock), `GslAlarmReceiver` (уведомление или будильник),
`GslAlarmActivity` (экран будильника поверх блокировки, звук, вибрация), `GslBootReceiver` (после перезагрузки),
`GslWidget` (виджет). Здесь — веб-сторона:

| Файл | Что внутри |
|---|---|
| `native.js` | `isApp()`, `call()`, `nativeItems()` (напоминания на 7 дней из `reminders/plan.js`), `widgetDays()` (виджет на 7 дней), `start()` |
| `../screens/settings/native-card.js` | Раздел настроек «Виджет и будильник»: разрешения телефона, будильник для утра/обеда/вечера, «Добавить виджет» |

Пока приложение открыто внутри APK, браузерные напоминания (`reminders/local.js`) молчат — их заменяют родные.
В браузере родная часть молчит, а настройки предлагают скачать приложение.
