# letters — письмо себе в будущее

Владелец 14.11.2026: «письмо самому себе через год, через 5, через 10 — или любую цифру он сам выставляет; максимум
3 письма; у ребёнка — можно вместе с родителями; и у мужчины, и у женщины — в разделе «Цели»».

| Файл | Что внутри |
|---|---|
| `letters.js` | Счёт: день открытия (через N лет), запечатано ли, сколько ждать, не больше трёх запечатанных; ящик взрослого (`ownBox`, ключ `letters`) |
| `letters-view.js` | Карточка: конверты (запечатан · пришёл · открыт) и новое письмо (с чего начать, когда открыть, «вместе с родителями» у ребёнка) |
| `texts.js` | Тексты (русский, положительными словами), `lt()` |
| `letters.css` | Вид |

Стыковка: «Цели» → «Мои» (`screens/goals/goals.js`, ящик `ownBox`, синхронизация — `sync/sync.js`, вид `letter`);
детский кабинет «Мечты» → «Письма» (`kids/kid-app.js`, ящик — записи семьи `letter`). Проверки — `tests/letters.test.js`.
