# Стержень недели (мужская часть)

Владелец 15.11.2026: «Мудрость недели забираем — перегруз для мужчины, а делаем стержень; задание остаётся».
Одно упражнение на неделю для мужской стороны — по Р. Гловеру «Хватит быть славным парнем!» (и немного Ф. Богачёв).

- Тексты — с сервера, поле `stem` программы мужской части (`planner/server/src/men/stem/`). У женской части его нет.
- `stem.js` — `stemOf(plan, lang, profile)` (слова под профиль, дни 1–6) и `stemCard(ctx, plan)` — карточка на «Сегодня»
  наверху, над стаканом воды; слова автора — цитатой, под ней подпись.
- «Сделал» — +1 балл (`score/deeds.js`, вид `stem`); тексты кнопок — ключ `stem` в `js/texts/*/`.
- Стыковка — одна строка в `screens/today/today.js`, одна — в `score/score.js`.
