# search — «В поиске»

Владелец 15.11.2026: у кого профиль «В поиске», на «Сегодня» вместо «Знакомства» — раздел действий: что делать,
пока ищешь. «Знакомство» (`../meet/`, шпаргалка к встрече и запись после свидания) остаётся в библиотеке, сюда из
раздела ведёт ссылка.

- Тексты — с сервера, поле `meet.search` программы части: `planner/server/src/{woman,men}/meet/search-ru.js`
  (сначала ты, где искать, ритм недели, переписка, пирамида мужчин / женщина плюс-ноль-минус с дословными словами
  автора, признаки надёжного человека, уважение и близость; у каждого блока подпись).
- `steps.js` — «Мои действия на 7 дней»: переписка, выходы в люди, знакомства, свидания. Счёт — 7 дней от дня
  старта человека (дни 1–7, 8–14… программы; старта нет — с понедельника). Цели — в текстах сервера (min / full / max).
  Ключ `searchsteps`, уходит в копию (`../sync/`, вид `searchstep`).
- Вид (утверждённый эскиз 16.11.2026, `../screens/search/search.js → stepsList`): одно поле; название и число зелёным;
  кружок со стрелкой над «+» — «что считается» (hint с сервера); полоска-батарея — деление на действие, «−» слева,
  «+» справа, отметки мин / 100% / макс подписаны всегда, после максимума — пунктир «можно больше».
- Экран — `../screens/search/` (`#/search`).
- **Карточка на «Сегодня»** (профиль `single`, сборка 90) — такая же, как остальные карточки дня: подпись, строка,
  круглая стрелка, раскрывается на месте; внутри — шаги недели (`stepsList` экрана) и ссылка на весь раздел.
  Отметил хоть один шаг сегодня — «+1 балл» зелёным у названия и в итоге дня (`../score/`, часть `search`).
  Отметки дня — ключ `searchday` `{ ISO: { n } }`, уходит в копию (вид `searchday`): балл один на всех телефонах.
