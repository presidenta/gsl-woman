# Анкеты «Пять языков любви»

С 22.11.2026 (владелец: «старую анкету, простую, везде удали; эти две новые вставляй — пускай работают на благо
проекта») вместо короткого теста на 7 вопросов — две анкеты с сайта анкет
[otkrytie-puti](https://presidenta.github.io/otkrytie-puti/):

| Кому | Анкета | Вопросов |
|---|---|---|
| «Мой язык» | о себе (`self`): три ответа по приоритету 1 · 2 · 3, минута на вопрос | 22 |
| «Мой мужчина» / «Моя женщина», «Родные» | по наблюдению (`observe`), взрослый: 1–3 ответа или «Не замечал(а)» | 17 |
| «Мои дети» | по наблюдению: сначала выбор — ребёнок 3–12 (18 вопросов) или подросток 12–18 (16) | 18 / 16 |

**С 184 (владелец 24.11.2026):**
- отмечать можно от одного до трёх ответов по важности: 1 — самое важное, потом 2 и 3; третий — не обязательно.
  Правило написано во вступлении (`love.quiz.howSelf` — у анкеты о себе вместо фразы сайта «отметь три») и под
  каждым вопросом (`love.quiz.rankHint`);
- цифры 1 · 2 · 3 — крупные и жирные, на весь кружок (рубленый шрифт: у заголовочного цифры старого начертания);
- **итог сохраняется сам**, как только анкета пройдена (`onResult` → `love/love.js` → `setResult`: у «Мой язык»,
  мужчины/женщины, каждого ребёнка и каждого из родных — свой). На экране под человеком — все пять языков в процентах,
  кнопка становится «Результат анкеты» и открывает итог с датой; «Пройти ещё раз» — заново, новый итог заменяет прошлый.
  Итог лежит в записи `love` — синхронизируется между устройствами вместе с выбором языков.

Итог — как на сайте: все пять языков в процентах, форма профиля, советы. Кнопка «Это язык …» сохраняет главный язык
(`love/love.js` → `choose` / `setPerson`), дальше всё как раньше: дело дня, утреннее напоминание, я-сообщения.
Названия языков в итоге — из программы (как везде в приложении), описания и советы — из анкет.

## Файлы

| Файл | Что |
|---|---|
| `quiz.js` | Механизм: вступление, вопрос, таймер, подсчёт `score`, форма профиля `shapeOf`, итог |
| `self-ru.js`, `self-ua.js`, `self-en.js` | Тексты анкеты о себе — **копия с сайта**, создаёт `npm run love-quiz` |
| `observe-ru.js`, `observe-ua.js`, `observe-en.js` | Тексты анкеты по наблюдению — **копия с сайта**, создаёт `npm run love-quiz` |
| `love-quiz.css` | Вид: отметки 1 · 2 · 3, таймер, шкалы |

Тексты правятся **только на сайте** (`D:\genesis\otkrut put test\love\`, `…\love-observe\`), потом
`npm run love-quiz` (путь — первый аргумент или `OTKRYTIE_PUTI`), `npm run files`, `npm test`.
Языки анкет — русский, украинский и английский (английский — с 22.11.2026, сборка 168).

`index.html`. Проверки — `tests/love-quiz.test.js`. Убрать — удалить папку и эти строки.
