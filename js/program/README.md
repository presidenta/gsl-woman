# Программа на 24 недели

Что женщина делает в день N. Экраны и напоминания берут это только через `index.js`.

**Текстов программы здесь нет.** Сайт открытый, а программа платная: она лежит на сервере «Кванта»
(`server/src/woman/program/` в planner, закрытый репозиторий) и приходит только после входа аккаунтом
«Кванта». Здесь — ритм недели и то, как программа попадает на телефон.

| Файл | Что внутри |
|---|---|
| `source.js` | Откуда программа: `GET /api/woman/program` после входа, копия на телефоне (ключ `program`), сверка отпечатка `version` при открытии с сетью, стирание при выходе |
| `index.js` | `dayPlan(day, lang)` — день целиком; `weekPlan`, `outline` — для недели и пути. Программа не пришла — `null` / `[]` |
| `morning.js` | Утренняя минута: пятки каждый день + добавка по кругу |

## Устройство недели (так её присылает сервер)

```js
{
  title: '…',
  intro: '…',               // необязательно — вступление недели («Ангел-Хранитель»)
  tasks: [                  // задания дней по порядку
    { title, text, levels: { min, full, max } },   // levels необязательно
  ],
  flow: '…',                // свободный поток (дни после заданий)
  call: '…',                // седьмой день: итог и созвон
}
```

- 3 задания → дни 1–3 задания, 4–6 свободный поток, 7 созвон (обычная неделя);
- 6 заданий → дни 1–6 задания, без свободного потока (неделя 5, зеркало);
- 0 заданий → дни 1–6 свободный поток (неделя 24, финал).

Конец месяца (недели 4, 8, … 24) — в седьмой день добавляется «Отзыв месяца»; это считает
`isReviewWeek`, в данных ничего отмечать не нужно.

## Поменять задание

Правка на сервере: `server/src/woman/program/ru.js`, то же — в `ua.js` и `en.js`, проверки сервера,
выкладка сервера (README рядом с программой). Приложение трогать не нужно: отпечаток сменится, и новый
текст придёт женщинам при следующем открытии с сетью.

Проверки приложения (`tests/program.test.js`) идут на учебной программе того же устройства —
`tests/fixtures/program.js`, без настоящих текстов.
