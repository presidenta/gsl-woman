# Синхронизация между устройствами

Владелец 13.11.2026: «на компьютере всё заполнено, а на телефоне пусто — синхронизация обязательно». Устроено
точно как у GoldenFit: сервер «Кванта» хранит копию (`POST /api/woman/sync`, таблица `woman_records`, миграция 021,
`planner/server/src/woman/sync.js`), не разбирая данные: вид, ключ, данные, время правки.

**Что синхронизируется** (`COLLECTIONS` в `sync.js`): записи (каждая отдельно), цели, отметки утренней минуты по
дням, настройки, «Пять языков любви». Фото — следующим шагом. Остальные модули о синхронизации не знают: модуль
сам замечает изменение ключа хранилища и сравнивает с «тенью» (отпечатками уже согласованного с сервером).

**Правила:**
- побеждает более поздняя правка; удаление доходит до других устройств пометкой;
- без сети правки копятся в очереди и уходят, когда связь появится; приложение работает как раньше;
- первый раз на устройстве: сначала забираем то, что уже на сервере; настройки и языки — с сервера, если они там
  есть; из списков — добавляем то, чего на сервере нет. Пустой телефон не затрёт полный кабинет;
- на устройство вошла другая женщина — данные прежней с него убираются, в кабинет новой не уходят.

**Когда сверяется:** при открытии, после входа, через 2 секунды после правки, при возвращении в приложение,
при появлении сети и раз в 5 минут. В настройках под аккаунтом — строка «Копия на сервере сохранена: 12:03»;
нажатие — сверить сейчас.
