# secret — «Секретные материалы»

Владелец 22.11.2026 (решение консилиума): досье «Секс, деньги и чакры» главами — **7 глав, по чакре, раз в 2 дня**.
У него и у неё глава одна, задания — свои; в последней главе — задания паре. Строчка-интрига о следующей главе —
внизу карточки.

- **«Сегодня»** — карточка главы под делом дня: гриф, «Секретные материалы · Глава № N», чакра, «Читать главу»,
  «Читать глубже», задания, «Следующая глава — через 2 дн.: …», «Открыть всё досье». Только в день главы и на день
  после — в остальные дни её нет.
- **«Тайный архив»** — первая плашка «Секретные материалы»: открытые главы читаются, закрытые — с грифом и «откроется
  через N дн.». Всё досье (книжечка) — тут же, отдельной плашкой, открыто всегда.
- **Когда** — `schedule.js`: от дня программы, в который человек впервые встретил раздел (`secret:start`); с первого
  дня программы — первая глава на 2-й день. День — тот, что на экране (у администратора — за стрелками).

| Файл | Что |
|---|---|
| `secret.js` | `secretCard(ctx)`, `secretPlate(ctx)`, `chapterBody(ch)` |
| `schedule.js` | расчёт глав по дням |
| `texts.js` | надписи ru / ua / en |
| `secret.css` | вид |

Тексты глав и заданий — с сервера (`planner/server/src/gsl/secret/`). Стыковка: `screens/today/today.js` (под делом
дня), `screens/library/library.js` (первая плашка), стиль — строка в `index.html`. Проверки — `tests/secret.test.js`.
