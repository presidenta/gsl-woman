# team — «Командная цель семьи»

Владелец 21.11.2026: «10 звёзд за день; лучший день в неделе, итог недели — какой лучший день был, кто сколько внёс;
ребёнок видит, кто сколько делает; может быть мама и ребёнок, папа и ребёнок — без разницы». Семья соревнуется сама
с собой: общих рейтингов нет (владелец их отменил).

- **Цель дня** — 10 звёзд на всю семью (родитель меняет: 3–50). У каждого ребёнка своя **доля** — 2 звезды (0–10).
  Цель взята, когда набраны звёзды **и** доля каждого ребёнка: ребёнок в команде, его вклад обязателен.
- **Звёзды** — те же, что у «Мечты нашей семьи» (`kids/stars.js`): дела ребёнка по подтверждению родителя, дела
  семьи, сделанные взрослыми, «＋ Звезда» от родителя. День — день самого дела: подтвердили утром — звёзды во вчера.
- **Неделя** (пн–вс): семь клеток со звёздами, золотые — цель взята, корона — лучший день; «Дней с целью»,
  «Лучший день», «Кто сколько внёс за неделю»; ниже — «Итог прошлой недели».
- Карточка — только в семье с детьми: у ребёнка на «Сегодня» (вместо «Звёзд семьи за неделю» — та же неделя, плюс
  цель дня и дни), у родителя в «Мы → Семья» над «Мечтой нашей семьи». Родитель — «Цель команды» (две кнопки ‹ ›).
- Запись семьи `teamgoal`, id `goal`: `{ target, share, by, at }` — пишет только родитель (сервер:
  `planner/server/src/circles/circles.js` → `PARENT_KINDS`).

| Файл | Что внутри |
|---|---|
| `team.js` | Счёт: `goalOf`, `starsOfDay`, `dayResult`, `weekResult`, `weekStart`, `hasKids` |
| `team-view.js` | `teamCard(api, { rerender })` — карточка |
| `texts.js` | Тексты на трёх языках, `tt()` |

**Стыковка вне папки:** `kids/kid-app.js` (карточка на «Сегодня» ребёнка), `screens/us/us.js` (семья у родителя),
`index.html` (стиль), `files.js` (`npm run files`). Проверка — `tests/team.test.js`.
