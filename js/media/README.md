# Фото

Снимки к записям и фото профиля. Лежат только на телефоне — в своей базе IndexedDB `gsl-woman-media`
(в localStorage снимки не помещаются). Запись хранит только номера снимков (`entry.photos`, до шести).

| Файл | Что внутри |
|---|---|
| `photos.js` | База: сохранить с ужатием (1600 точек, JPEG), адрес для `<img>`, удалить, `prune()` — стереть ненужные |
| `photo-field.js` | Поле «Фото» в форме записи (плитка «+»: камера или галерея) и ряд снимков в карточке записи |
| `viewer.js` | Просмотр во весь экран: листать пальцем, стрелками, кнопками |
| `media.css` | Вид всего этого |

Снимок ложится в базу сразу при выборе, в запись — по «Сохранить». Лишние (убрали, не сохранили, удалили
запись) стирает `prune()` — после сохранения и при каждом запуске (`main.js`). «Стереть все мои данные»
стирает и базу. Копии на сервере пока нет — как и у записей.
