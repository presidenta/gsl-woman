# quest — квест «Я⁺ • Любовь»

Владелец 18.11.2026: «GSL • Global Life Game. Квест № 1 в мире — Я⁺ • Любовь. Игра длиною в жизнь. Играй.
Развивайся. Люби. Создавай. Зарабатывай.»

| Файл | Что внутри |
|---|---|
| `quest.js` | `questMark()` — название игры золотой меткой (Я с плюсом в степени • Любовь) на языке приложения; `questBanner()` — картинка приветствия на языке приложения |
| `quest.css` | Вид метки и баннера; класс `quest-scene` — изумрудно-золотая сцена нейтральных экранов |
| `../../assets/quest/banner-{ru,ua,en}.webp` | Картинки владельца (из «Загрузок», 1280 px, webp) |

Тексты — ключи `quest.*` в `js/texts/{woman,man}/{ru,ua,en}.js` (me, love, mark, кавычки, bannerAlt). Слоган — только на картинке (19.11.2026).

Стыковка:
- вход (`screens/login`) и выбор части (`screens/gender`) — картинка на всю ширину с продолжением вниз и сцена
  `quest-scene` «тёмный изумрудный лес» (19.11.2026); золото — жёлтое, как на картинке (`side-man.css`, `:has`);
- «Совместные квесты «Я⁺ • Любовь»» — заголовок раздела «Мы» (`screens/us`);
- «Настройка «Я⁺ • Любовь»» — заголовок настроек (`screens/settings`);
- «Квест «Я⁺ • Любовь»» — экран «Квест» (`screens/path`), под ним «Игра длиною в жизнь»;
- «Приглашение в квест «Я⁺ • Любовь»» — код для любимого (`screens/us`);
- мелкая метка под названием в шапке (`main.js`); утреннее напоминание — «Квест дня «Я⁺ • Любовь» ждёт тебя».

Золото — только общее золото проекта (`--g-gold-text`, вырезка из фотографии: у женщин розовое, у мужчин жёлтое);
своего золота у модуля нет. Плюс — в степени, крупный и жирный, как буква (так же `.brand__plus` в `styles/base.css`).

Убрать модуль — эта папка, `assets/quest/`, строка `quest.css` в `index.html` и вызовы в трёх экранах.
