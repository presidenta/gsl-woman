# Пара идёт день в день

Решение владельца 17.11.2026. Начинать можно в любой день; **кто создал пару — задаёт день**. Второй, войдя в пару,
встаёт на тот же день программы: у неё «Магия рук» — у него «Дверь — моя», выходной общий.

- Дата старта первого лежит в паре записью `pace/start` (`{ startDate }`).
- Второй берёт её себе при первой же сверке с сервером. Его записи остаются, меняется только счёт дней.
- Первый сменил дату — второй идёт следом. Вышли из пары — каждый считает сам.
- Кнопок и вопросов нет.

`pace.js` → `apply()`; стыковка — одна строка в `js/main.js` (`context()`), перед чтением настроек.
