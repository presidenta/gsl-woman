# help — «Помощь»

Решение владельца 14.11.2026: один раздел-библиотека вместо отдельных кнопок. Вход — «Цели», под «Письмом себе в
будущее». Внутри:

1. **Первое свидание** — ссылка на экран «Знакомство» (`../meet/`, `#/meet`).
2. **Вопросы для разговора** — у мужчины ей, у женщины ему, папками: «Три вопроса — когда мало времени», шесть
   вопросов, «Карта любви» (36 вопросов Артура Арона и вопросы супругов Готтман, с источниками), о деле, как слушать;
   под вопросами — «как понимать ответ».
3. **Общие темы для обсуждения** — 10 тем.
3½. **Правила нашего дома** — отдельный пункт: «＋» — дописать, нажать — изменить, «−» — убрать.
4. **Комплименты** — мужчине для неё, женщине для него.

| Файл | Что внутри |
|---|---|
| `help.js` | `content(lang)` — тексты с сервера (поле `help` программы части) |
| `rules.js` | «Правила нашего дома» человека: в первый раз — из правил с сервера, дальше `add` (＋), `update` (нажать — изменить), `remove` (−); ключ `houserules`, копия на сервере — вид `houserules` |
| `../screens/help/` | Экран `#/help`: разделы складываются и раскрываются по нажатию |

Тексты правятся на сервере: `planner/server/src/men/help/ru.js`, `src/woman/help/ru.js`, общее —
`src/gsl/help/common-ru.js`. Источник — база знаний `D:\Файлы\GSL — база знаний\`.
