# shortcut — своя кнопка на нижней панели

Кнопка между «Сегодня» и «Артефактами» (до сборки 239 там было «В разработке», ещё раньше — «Неделя»). Что она открывает, человек выбирает сам. Решение владельца — 28.11.2026.

## Как выглядит

- **На панели.** Большой значок выбранного раздела, под ним короткое название. В правом верхнем углу значка — маленькая золотая шестерёнка: нажал — карточка «Своя кнопка» в настройках, она коротко вспыхивает. Зона нажатия у шестерёнки шире её самой.
- **Пока ничего не выбрано.** Вместо значка — «?» в пунктирном круге, подпись «Выбрать»; нажатие ведёт в настройку.
- **В настройках.** Карточка стоит первой и светится золотом. В ней виден вид кнопки и выпадающий список вариантов — родной список телефона.

## Варианты

Список — `options.js`. «Недели» в нём нет: владелец сказал, что она точно не нужна.

| Вариант | Куда ведёт |
|---|---|
| Продолжить с того же места | последний просмотренный раздел (`resume.js`) |
| Чат пары | `#/us?pair` |
| Семейный чат | `#/us?family` |
| Библиотека | `#/library` |
| Кто перед тобой (архетипы) | `#/library?open=types` — плашка сразу открыта |
| Вопросы для разговора | `#/help` |
| Разбор по дате рождения | `#/charts` |
| Пять языков любви | `#/love` |
| Красный флаг | `#/redflag` |
| Интим 18⁺ | `#/intim` |
| Анкета партнёра | `#/anketa` |

## «Продолжить с того же места»

Запоминается последний раздел, кроме «Сегодня» и настроек:

- адрес;
- какие плашки и главы открыты — их номера по порядку на странице;
- докуда пролистано.

Кнопка возвращает всё это: тот же раздел, те же открытые главы, то же место.

Место хранится на этом телефоне и записывается тихо (`writeQuiet`), чтобы экран не перерисовывался при каждой прокрутке. Возврат делается сразу после отрисовки экрана. Через 0,35 с прокрутка повторяется ещё раз: к этому времени догружаются картинки и сдвигают страницу.

## Стыковка

- `main.js`: на панели — `shortcut.navItem(settings.get().shortcut)`; после каждого перехода — `shortcut.entered(name)`.
- `screens/settings/settings.js`: `shortcutCard(ctx)` первой карточкой.
- `settings/settings.js`: поле `shortcut` (по умолчанию `null`).
- `screens/us/us.js` — `onEnter` читает `?pair` или `?family`; `screens/library/library.js` — `onEnter` читает `?open=`; `screens/help/help.js` — `openPlate()` и `data-plate` у плашек.
- Стили — `shortcut.css`, подключены в `index.html`. Проверки — `tests/shortcut.test.js`.
