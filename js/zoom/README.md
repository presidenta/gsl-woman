# zoom — картинка на весь экран с увеличением

`openZoom(node, hint?)` — показывает `<img>` или `<svg>` на весь экран:

- двумя пальцами — растянуть (до 4 раз);
- одним пальцем — двигать увеличенное;
- двойное касание — крупнее или назад;
- колёсико мыши тоже увеличивает;
- закрыть — крестиком, Esc или касанием мимо картинки.

Модуль общий с 235, до этого жил в квесте. Стили — `zoom.css`, подключены в `index.html`.

Кто пользуется:

- квест — картинка входа (`js/quest/quest.js`);
- матрица Ладини — рисунок с кругом возрастов (`js/charts/matrix/view.js`): мелкие цифры на круге читают здесь.
