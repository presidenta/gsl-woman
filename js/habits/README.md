# habits — привычки дня: Кегель и шаги

Владелец 13.11.2026, сборка 42; ТЗ — `docs/TZ-para-semya.md`, раздел 8. На «Сегодня» — в конце, сворачиваются
(`ui/fold.js`). Утренние привычки — стакан воды (`water/`) и утренняя минута (`screens/today/`).

| Файл | Что внутри |
|---|---|
| `logs.js` | Отметки по дням: `kegel[iso] = { level }` (лучший уровень), `steps[iso] = { n }`; уровни шагов 3000 / 6000 / 12 000 |
| `kegel-card.js` | Карточка Кегеля: Минимум 10×3 с, 100% 3×10×5 с, Максимум 3×10×10 с (Mayo Clinic); таймер «сжать / расслабить» со звуком; отметка — сама |
| `steps-card.js` | Карточка шагов: кнопки уровней или своё число, полоса до 12 000 |
| `figures.js` | Фигуры из `ui/heels.js` под своими id: свечение в области таза (Кегель) и идущая фигура на движущейся дороге |
| `habits.css` | Вид и движения |

Итоги — `insights/habits.js`: «Утро» (вода, минута) и «День» (Кегель, шаги). Синхронизация — `sync/` (виды
`kegel`, `steps`).
