# intim — «Интим 18⁺»

Владелец 21.11.2026: «делаем раздел Интим 18⁺ (плюс в степени) — видят в паре и отдельно мужчина и женщина, для себя;
Готтманы и Перель; карта желаний — только «да» и «может быть», «нет» не отмечаем; массажи и игры подробно; красный
флаг и стоп-слово; задания на выходные — суббота или воскресенье, на полгода».

- **Экран** `#/intim` (`screens/intim/intim.js`): плашки «Красный флаг: договор и стоп-слово» (раскрыта), «Почему это
  важно», «Карта желаний», «Массажи», «Игры», «Задания на выходные». Вход — первая плашка «Библиотеки» и ссылка из
  карточки выходного.
- **Карта желаний** (`map.js`, `map-view.js`): «Да / Может быть», «＋ своё» в каждом разделе. Своя карта — на телефоне
  (ключ `intimmap`, копия на сервере через `sync/`); в паре отметки дублируются в контур: вид `imark`
  `{ key, mark }`, свои желания — `iwish` `{ section, text }`. Второму видны **только совпадения** (оба «да» — 🔥).
  Отмеченное до пары переносится в контур при открытии карты (пишется только недостающее).
- **Интим-квест выходного** (`weekend.js`): карточка в «Отношениях» на 6-й и 7-й день, задание недели (24, по кругу),
  шаги и три уровня, «Сделали» — +1 балл в день отметки (`score/deeds`, вид `intim`); без пары — строка `solo`.
- **Тексты** — с сервера, поле `intim` (`planner/server/src/gsl/intim/`); надписи модуля — `texts.js` (`it()`).
