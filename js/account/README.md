# Аккаунт «Кванта»

GSL Woman входит аккаунтом «Кванта», как спорт: своих пользователей и паролей нет, логин и пароль —
те же, что в «Квантовом ежедневнике» (почта или номер кабинета). Кабинет выдаёт администратор
«Кванта», регистрации здесь нет. Сервер — `https://game.coreviaflow.com/genesisystem`
(`js/config.js` → `API_BASE`; открыто с localhost по http — свой сервер на 8580).

| Файл | Что внутри |
|---|---|
| `session.js` | Сессия (ключ `account`), запросы к серверу, вход паролем и по пропуску из «Кванта», выход, сверка имени |
| `avatar.js` | Фото профиля (своё, на телефоне), кружок «кто вошёл» для шапки, карточка «Аккаунт» в настройках |
| `account.css` | Вид кружка, шапки и карточки |

Экран входа — `js/screens/login/`, карточка «Аккаунт» — в `js/screens/settings/`.

## Зачем вход

Программа платная, а сайт открытый — поэтому в коде сайта её нет. Она приходит с сервера только
вошедшей (`js/program/source.js`, `GET /api/woman/program`) и хранится на телефоне: дальше всё работает
без интернета.

## Что происходит

- **Вход** → сессия → программа с сервера → первый вход (имя подставляется из аккаунта) → экраны.
- **Каждое открытие с сетью** — сверка отпечатка программы и имени; без сети — всё как было.
- **Выход** (настройки) — сессия закрывается и на сервере, копия программы стирается. Записи остаются
  на телефоне: войдёт снова — всё на месте.
- **Сервер больше не принимает сессию** (вышла на всех устройствах, блок, кончился срок кабинета) —
  то же, что выход, и на экране входа объяснение.

## Потом

- **Доступ по направлениям.** Сейчас пускает любой действующий кабинет «Кванта». Когда администратор
  будет выдавать доступ к GSL Woman отдельно — проверка встанет на сервере (`server/src/woman/index.js`),
  здесь менять ничего не нужно: отказ придёт тем же 401/403 и покажется на экране входа.
- **Копия записей и фото на сервере** — когда решим.

## Вход из «Кванта»

Плитка GSL Woman в «Кванте» (`web/js/views/woman/` в planner) открывает сайт с `#kvant=<пропуск>`
(2 минуты, один раз). `main.js` → `takeKvantLink()` меняет его на сессию (`POST /api/woman/redeem`) и
стирает из адреса. Уже вошла — пропуск не нужен. Пропуск устарел — экран входа с объяснением.
