## Устройство

Одна папка — одно место матрицы. В папке три файла: `ru.js`, `ua.js`, `en.js` с одинаковыми ключами:

- `ui` — подписи этого места (заголовок, подписи абзацев);
- `text` — тексты по числам 1–22;
- у хвоста ещё `intro` — общее вступление.

Стыковка — `index.js`: `PL('tail').text[n]`. Проверка `tests/charts-texts.test.js` сверяет ключи трёх языков.

| Папка | Место | Точки | Источник |
|---|---|---|---|
| `tail/` | кармический хвост | Г2 · Г1 · Г | «Кармический хвост» (3–22); для 1–2 — «Негативная карма» + «Рекомендации» из PDF |
| `work/` | работа | Б2 (третья сверху) | PDF «Расшифровка 22-х кодов судьбы» (Д. Воронов по книге Н. Ладини), «Рекомендуемая деятельность» |

## Правила текста

- Готовый текст берём почти дословно: убраны ритуалы (вода, кольца, «Благословляю»), ссылки, реклама, опечатки.
- Если для места текста нет — выдержка из полного описания аркана (PDF), не своими словами.
- Заменить текст = поправить одну строку в нужном файле; на других местах это не скажется.
