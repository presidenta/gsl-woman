# anketa — «Единая анкета партнёра»

Владелец 26.11.2026: анкета для знакомства и для пары. Мужская и женская заполняются отдельно; как только второй
человек заполнил свою — у обоих «Наш итог». Сервер и решения по содержанию — `planner/server/src/gsl/anketa/README.md`.

- **Экран** `#/anketa` (`screens/anketa/`): «Отправить анкету» (ссылка), «Наш итог» (с парой и с каждым, кто заполнил по
  ссылке, — и без пары), сама анкета: «Главное» (5 блоков) и «По желанию». `#/anketa?result` — сразу к итогу.
- **Входы:** «Артефакты» → «Анкеты» (первой), «В поиске», «Знакомство», «Мы» → пара («Наш итог»).
- **Без повторов:** языки любви — два главных из «Пяти языков любви» (`love/`), интим — отметки «Карты желаний»
  (`intim/map.js`); на сервер уходят вместе с ответами. Карты на телефоне ещё нет (новый телефон) — отметки не шлются,
  сервер оставляет прежние.
- **Итог** считает сервер; без процентов: «совпало · попробовать · обсудить»; интим — только совпадения; данные
  рождения — только у самого человека.
- **Ссылка-приглашение** — одна, постоянная: `https://presidenta.github.io/gsl-woman/anketa.html#<token>`. Страница гостя
  (`anketa.html` + `public.js`) работает без входа: имя, «я — женщина / мужчина», та же форма (интим — картой прямо в
  анкете), «Хочу квест для себя» — заявка на доступ (одобряет администратор). Черновик и итог гостя — у него в браузере.

| Файл | Что |
|---|---|
| `data.js` | ответы на телефоне (ключ `anketa`, тихая запись), отправка и сверка с сервером, ссылка, итоги |
| `form.js` | вид анкеты — общий для приложения и страницы гостя |
| `result.js` | вид «Нашего итога» |
| `public.js` | страница гостя |
| `link.js` | ссылка на анкету с других экранов |
| `texts.js` | надписи (пока русский) |
| `anketa.css` | вид |

Стыковка вне папки: `main.js` (маршрут и список экранов), `index.html` (стиль), `screens/goals/goals.js`
(`surveysPlate`), `screens/search/search.js`, `screens/meet/meet.js`, `screens/us/us.js`. Проверки — `tests/anketa.test.js`.
