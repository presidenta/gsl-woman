# circles — «Пара» и «Семья»

Владелец 13.11.2026, сборка 42; ТЗ — `docs/TZ-para-semya.md`; сервер — `planner/server/src/circles/`.

| Файл | Что внутри |
|---|---|
| `circles.js` | Контуры и общие записи на телефоне (`circles`, `circle-data`), правки `put`/`drop`, обмен с сервером по номеру правки, опрос раз в 30 с на экране, непрочитанное, связка (создать, код, войти, выйти, дети) |
| `chat-view.js` | Чат пары и семейный чат: быстрые сигналы (помощь, поддержка, срочно, спасибо, идея), переписка по дням |
| `wishes.js`, `wishes-view.js` | Желания на выходные: «Хочу» (Да / Может быть / Пас; «Близость» — Откликается / Подумаю) и «Дарю»; совпадения |
| `catalog/` | Готовые желания на трёх языках — общие для обеих частей |
| `goals-model.js`, `goals-view.js` | Общие цели: шаги с весом % и исполнителем, счётчик (сам набирается от привычек); вкладки «Пара», «Семья» в «Целях» |
| `family-view.js` | Дети (заводит родитель) и их мечты и цели |
| `talk.js` | «Разговор пары» — карточка седьмого дня на «Сегодня», «Мы поговорили» |
| `today-card.js` | Карточка нового сообщения на «Сегодня» («Срочно» — красная) |
| `circles.css` | Вид всего раздела |

Экран — `screens/us/` (`#/us`), значок «Мы» в шапке (`main.js`). Очки и рейтинги отложены (ТЗ, раздел 9): все
отметки хранятся по дням с автором — посчитать потом можно из них.
