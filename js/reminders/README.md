# Напоминания

| Файл | Что делает |
|---|---|
| `plan.js` | Считает расписание: три сообщения в день, текст по виду дня; красная метка 🔴 для заголовка (`noticeTitle`). Ничего не отправляет |
| `server.js` | Отдаёт расписание на неделю серверу — в час напоминания сервер присылает пуш (и при закрытом приложении, и на iPhone) |
| `local.js` | Пока приложение открыто: красная плашка со звуком; свёрнуто, а сервер расписание не принял — системное уведомление через `sw.js` |
| `nudge.js` | Красная плашка «Напоминания со звуком» на «Сегодня», пока напоминания выключены, а включить их можно |
| `permission.js` | Разрешение на уведомления (только по нажатию) |
| `texts.js`, `reminders.css` | Надписи и цвет плашки |

Тексты самих напоминаний — `notice.*` и `compliments` в `js/texts/<часть>/<язык>.js`.

## Как приходит напоминание (с 193, владелец 25.11.2026: «на айфоны не приходят — чтобы как будильники, со звуком, красным»)

| Где | Чем | Звук |
|---|---|---|
| iPhone — GSL на экране «Домой» (iOS 16.4+) | пуш с сервера | звук уведомлений iPhone, если для GSL он включён в «Настройки → Уведомления» |
| iPhone — в Safari без значка | никак: Apple не даёт сайту уведомлений; на «Сегодня» — красная плашка, как поставить значок | — |
| Android, компьютер — в браузере или со значка | пуш с сервера | звук и вибрация уведомлений, на экране до нажатия |
| APK для Android | будильник самого телефона (`native/`, `setAlarmClock`) | канал `gsl_remind_sound`: всплывает поверх экрана, звук, вибрация, красный оттенок; «будильник» — на весь экран, звук будильника |
| Приложение открыто | красная плашка и три звона (`ui/tick.js → alert`) | звук приложения — после первого касания экрана |

Сервер (planner `server/src/push.js`): расписание GSL хранится отдельно от «Кванта» (`push_plan.app`,
миграция 036) и уходит только на подписки GSL. Пуш помечен `kind: 'remind'` — работник показывает его со
звуком, вибрацией и `requireInteraction` (на экране до нажатия). Опоздавший больше чем на 30 минут не приходит.

Нужны вход аккаунтом «Кванта» и разрешение на уведомления. Расписание уходит на неделю вперёд, так что
напоминания идут, даже если приложение несколько дней не открывали.

По умолчанию в уведомлении нейтральная фраза, без текста задания: экран блокировки видят чужие.
Человек может включить текст в настройках.

## Чего сайт не умеет

Звонить как будильник — на весь экран и мимо беззвучного режима — умеет только APK для Android. На iPhone
пуш звучит обычным звуком уведомлений: свою мелодию и громкость будильника Apple сайтам не даёт, а в режиме
«Не беспокоить» или в беззвучном пуш придёт без звука.
