# Напоминания

| Файл | Что делает |
|---|---|
| `plan.js` | Считает расписание: три сообщения в день, текст по виду дня. Ничего не отправляет |
| `local.js` | Показывает подошедшее: на экране — плашка, свёрнуто — системное уведомление через `sw.js` |
| `permission.js` | Разрешение на уведомления (только по нажатию) |

Тексты — `notice.*` и `compliments` в `js/texts/<язык>.js`.

## Что сейчас работает

Пока приложение открыто или свёрнуто (но не закрыто) — напоминание приходит в своё время. Пропустила,
пока телефон спал, — придёт при открытии, если прошло не больше 30 минут.

По умолчанию в уведомлении нейтральная фраза, без текста задания: экран блокировки видят чужие.
Женщина может включить текст в настройках.

## Почему не будит закрытое приложение

Закрытый сайт сам будить телефон не может — ни на Android, ни на iPhone. Это умеют только:

1. **Пуши с сервера.** У «Кванта» они уже есть (`server/src/push.js` в planner, выкладка 205): приложение
   присылает расписание, сервер в нужный час шлёт пуш. Работает и на iPhone (значок на экране «Домой»,
   iOS 16.4+). `plan.js` выдаёт ровно ту форму, которую ждёт сервер: `{ key, at, title, body, target }`.
   Что понадобится: вход аккаунтом «Кванта»; на сервере — расписание этого приложения отдельно от
   расписания «Кванта» (сейчас `savePlan` заменяет всё расписание человека целиком и стёр бы чужое);
   здесь — подписка `pushManager.subscribe` и обработчик `push` в `sw.js`.
2. **Свой APK с будильниками**, как у «Кванта». Надёжнее на Android, но это отдельное приложение в сборке.

Решение — за владельцем (открытый вопрос №1 в документе).
