# score/ — баллы дня

Владелец 14.11.2026 (сборка 56): «не просто „выполнено“, а балл — человек сам видит, сколько баллов прожил за день».

- **Уровень**: Минимум — 1, 100% — 2, Максимум — 3. **Стакан воды** утром и на ночь — по 1.
- **Откуда**: только из отметок, своего хранилища нет — стакан (`water/water-log.js`), утренняя минута с уровнем
  (`journal/morning-log.js`: `{ level }`, старое `true` — Минимум), Кегель и шаги (`habits/logs.js`), задание дня —
  лучший уровень записей дня (`journal/`), созвон — 2.
- **Личные**: никуда не уходят и ни с кем не сравниваются — проверить их нельзя, поэтому рейтинга на них нет.
- **Где видно**: шапка «Сегодня» — «Баллы дня: N»; шапка каждой свёрнутой карточки — галочка и «+N» (`doneBadge`).
- Задание дня отмечается кнопками «Минимум · 100% · Максимум» прямо в карточке (запись дня с этим уровнем).
