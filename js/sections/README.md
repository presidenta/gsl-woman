# Разделы дня — кнопки в шапке «Сегодня»

Решение владельца 17.11.2026: день перегружен. Всегда на виду только **ядро дня** — задание, стакан воды утром и
на ночь, итог. Остальное разложено по трём разделам; у каждого кнопка в шапке дня: нажал — раздел открылся,
нажал ещё раз — закрылся («как конструктор»). Выбор помнится.

| Кнопка | Что внутри |
|---|---|
| **Отношения** | я-сообщение, вопрос на вечер, «Пять языков любви», «Разговор пары», повтор навыков, «В поиске» |
| **Здоровье** | утренняя минута, упражнение Кегеля, шаги |
| **Дело** | «Совет недели по работе» и «Стержень недели» — пока только у мужской части |

С самого начала открыты «Отношения»; «Здоровье» — у тех, кто уже отмечал Кегель или шаги; «Дело» закрыто.

| Файл | Что внутри |
|---|---|
| `sections.js` | `state()`, `toggle()`, `sectionButtons()` — кнопки, `sectionBlock()` — открытый раздел, `bizCard()` |
| `sections.css` | Кнопки и подписи разделов |

**Стыковка вне папки:** `screens/today/today.js` (кнопки в шапке, карточки по разделам), тексты `sections.*` в
`js/texts/{woman,man}/{ru,ua,en}.js`, `index.html` (стили). Добавить карточку в раздел — строка в `today.js`.
