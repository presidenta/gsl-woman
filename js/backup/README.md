# backup — копия всего на почту человека

Владелец 15.11.2026: «запрашивать у человека, хотите ли вы сохранить на свою почту… пока пускай будет как есть
(копия на сервере), но почту сделай, и чтобы запрос был». В перспективе всё своё человек хранит на своей почте, а не
на нашем сервере (напоминание — `docs/PLAN.md`, очередь, п. 7).

- `archive.js` — файл копии: JSON с тем, что синхронизируется (`sync/sync.js` COLLECTIONS), нужными снимками
  (`media/used.js` и фото профиля) и голосом к целям (base64). Возврат из файла **дополняет** телефон и ничего не
  стирает: записи с новыми номерами, недостающие дни, пустое одиночное, недостающие снимки и голос.
- `deliver.js` — отдать файл почте: в приложении для Android — родная часть (`GslNativePlugin.shareFile`, «Отправить»
  Android с адресом, темой и файлом); на сайте — «Поделиться» браузера; иначе файл скачивается.
- `index.js` — раздел настроек «Копия на твою почту» (`backupCard`) и вопрос раз в 30 дней после последней копии
  (`maybeAsk`, «Позже» — через 7 дней; только когда есть цели или записи). Ключ хранилища `backup`.
- `texts.js` — тексты ru / ua / en.

Почта — та, что указана при регистрации (`/api/me`). Наш сервер файл копии не видит и не хранит: письмо уходит из
почты человека. Стыковка: строка в `screens/settings/settings.js`, строка в `main.js`.
