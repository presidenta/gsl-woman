# kids — детский кабинет GSL

Владелец 14.11.2026; ТЗ — `docs/TZ-deti.md`; сервер — `planner/server/src/kids/` (вход ребёнка), записи — общие записи
«Семьи» (`planner/server/src/circles/`).

| Файл | Что внутри |
|---|---|
| `catalog.js` | Содержание: навыки по разделам, живые игры (правила, игроки, место, что развивает), идеи дел семьи, звёзды (1 за дело; родитель — 1/2/3/5/10), ступени роста, разделы мечт |
| `texts.js` | Тексты кабинета (только русский, положительными словами), `kt()` |
| `stars.js` | Счёт: звёзды ребёнка и взрослых, ступень, навык «Получилось → Умею → Мастер», что ждёт подтверждения, звёзды семьи за неделю |
| `kid-store.js` | Телефон ребёнка: вход по ссылке и паролю от родителя, «ждёт родителя», обмен записями семьи (`/api/kids/…`) |
| `kid-app.js` | Кабинет на телефоне ребёнка: Сегодня · Дела · Навыки · Игры · Мечты |
| `nophone.js` | «Играем вживую»: таймер на весь экран, экран горит, уход из приложения считается («телефон брали») |
| `tasks-view.js` | Дела семьи в семейном чате: «＋ Дело», «Беру», «Сделано», звёзды, подтверждение родителя |
| `parent-view.js` | «Мы» → «Семья» → «Дети»: вход ребёнка (пароль, ссылка, телефоны), подтверждения, навыки, игры, мечты |
| `family-api.js` | Кабинет родителя как участник семьи для общих экранов |
| `dreams-catalog.js`, `dream-stops.js` | Профессии с путями, идеи мечт семьи, остановки на пути, подсказки письма ребёнка |
| `family-dream.js` | «Мечта нашей семьи» — общий котёл звёзд, дорога с остановками, вклад каждого, «＋ Звезда за дело» |
| `careers.js` | «Кем я хочу стать»: до трёх профессий, путь из шагов, подтверждение родителя |
| `alerts.js` | Что ждёт родителя (телефон ребёнка, дела) — красная точка на «Мы» |
| `kids.css` | Вид: ночное синее небо и тёплое золото (`data-side="kid"`) |

Стыковка: `js/boot.js` (детский кабинет вместо взрослого, когда на телефоне вход ребёнка или ссылка `#kid=КОД`),
`screens/us/us.js` (вкладка «Дети»), `circles/chat-view.js` (дела в семейном чате), `index.html` (стили).

Записи семьи: `deed` (дело ребёнка), `ok` (подтверждение — только родитель), `task` (дело семьи), `plan` (задания
ребёнка на день), `friend` (друзья ребёнка), `dream` (мечты, у родителя — статус и пара слов), `fdream` (мечта семьи), `award` (звезда
от родителя — только родитель), `career` (профессии ребёнка), `letter` (письма ребёнка себе — `../letters/`).
Проверки — `tests/kids.test.js`.
