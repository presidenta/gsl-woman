# chakra-check — анкета «Чек-лист: 7 чакр в паре»

Владелец 22.11.2026: чек-лист книга «Секс, деньги и чакры» — анкетой в «Вопросах», «ближе к самой книжке», «и для тех,
кто в отношениях, и кто нет». Вопросы согласованы в разговоре дословно.

- **Одна анкета — два опросника**, разделены цветом: золотой блок «У вас дома» (про пару сейчас) и голубой
  «У родителей» (про семью, где человек вырос). Наверху — «Живём вместе» / «Встречаемся или пока одна»: во втором
  случае золотые блоки прячутся (впервые режим берётся из профиля отношений в настройках).
- **Часть 1 «Кто…»** — ответы Мужчина / Папа · Женщина / Мама · Оба · Никто (где есть); жильё — в два шага.
  **Часть 2** — «Да · Нет» к принимающей стороне чакры.
- **Итог** раздельно: «Как сейчас», «Как было у родителей», «Что повторяется», «Как должно быть» (из книги).
- Тексты и коды подсчёта — с сервера (`planner/server/src/gsl/chakra-test/`), у мужской и женской части свои слова.
  Ответы хранятся на устройстве (ключ `chakra-test`) — анкету можно проходить по частям.

| Файл | Что |
|---|---|
| `check.js` | `chakraCheck(group)` — узлы плашки |
| `score.js` | `points`, `leanOf`, `compare` — расчёт |
| `texts.js` | общие надписи ru / ua / en |
| `chakra-check.css` | вид: два цвета опросников |

Стыковка: `screens/help/help.js → questionPlates` (если `g.check`), стиль — строка в `index.html`.
Проверки — `tests/chakra-check.test.js`.
