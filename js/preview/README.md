# Просмотр дней — только администратор

Полоска со стрелками над экранами «Сегодня» и «Неделя»: ‹‹ неделя назад, ‹ день назад, «День N»,
день вперёд ›, неделя вперёд ››. Видна только аккаунту «Кванта» с ролью администратора (`/api/me` →
`role: 'admin'`), участницам её нет. Нужна владельцу, чтобы пролистать все дни программы и посмотреть
задания, вопросы и дизайн каждого дня.

Меняет только то, какой день показывают экраны (`dayFor()` в `main.js` → `ctx.day`). Дата старта,
записи и напоминания не трогаются; перезагрузка возвращает к настоящему сегодняшнему дню.
Запись, сделанная на просматриваемом дне, ложится в этот день — как обычная запись администратора.

Подключение вне папки: `main.js` (`dayFor`, `bar`, `onChange`), `<link>` на `preview.css` в `index.html`,
надписи `preview.*` в `js/texts/`, роль в сессии — `js/account/session.js`.
