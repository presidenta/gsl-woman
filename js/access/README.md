# Доступ к GSL Woman+

Как у «Кванта» (`planner/web/js/core/access-controller.js`), решение владельца 13.11.2026: администратор
«Кванта» в карточке человека ставит галочку «GSL Woman+» и срок (сервер — `server/src/access/apps.js` в planner).

- Срок приходит в `/api/me?app=gsl-woman` (`accessUntil`) — при входе, по пропуску из «Кванта», при каждом
  открытии с сетью и при возвращении в приложение (не чаще раза в 10 минут). Телефон хранит его (ключ `access`).
- Пусто — бессрочно: приложение работает всегда. Дата наступила — закрывается само, и без интернета.
- Сервер ответил `access_expired` (галочку сняли, срок вышел) — закрыто сразу.
- Закрыто — экран «Доступ закрыт» с кнопками «Проверить» и «Выйти», напоминания молчат, **записи целы**.

| Файл | Что внутри |
|---|---|
| `access.js` | `remember(accessUntil)`, `close()`, `isOpen()`, `until()`, `forget()` |
| `access.css` | Вид экрана «Доступ закрыт» |

Стыковка: `account/session.js` (запоминает срок, `isClosed`), `main.js` (`drawClosed`, `checkAccess`, напоминания).
