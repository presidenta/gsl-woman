# Значок на экран

Карточка в настройках, как у спорта: Chrome разрешил установку (`beforeinstallprompt`) — кнопка
«Поставить значок»; нет (iPhone, другой браузер) — подсказка, где это в меню. Открыто со значка — карточки нет.

Кнопка «Значок на экран» на плитке GSL Woman в «Кванте» открывает сайт с `#install=1`: `main.js` уводит в
настройки и зовёт `requestHighlight()` — карточка один раз вспыхивает золотом.
