# thanks — «Благодарность недели»

Владелец 19.11.2026 (`docs/PLAN.md`, очередь, п. 2): в паре на 7-й день каждый пишет одно, что ему понравилось у
партнёра за неделю, и видит запись партнёра.

- Карточка — на «Сегодня» в 7-й день недели программы, в разделе «Отношения», сразу за «Разговором пары»; в
  конструкторе «Разделы дня» — галочка «Благодарность недели» (включена).
- Только в связанной паре («Совместные квесты»). Пары нет — карточки нет.
- Запись уходит в контур пары: вид `thanks`, id `«понедельник недели».«участник»`, данные `{ week, text }` (до 600
  знаков). Свою правит и убирает только автор (сервер: `planner/server/src/circles/circles.js` → `OWN_KINDS`).
- Запись партнёра появляется у второго при обмене (открытие и раз в 30 с), как всё в паре.
- Своя запись есть — +1 балл дня (`score/score.js`, часть `thanks`).

| Файл | Что внутри |
|---|---|
| `thanks.js` | `thanksCard(ctx, plan)` — карточка; `thanksDone(ctx, plan)` — для баллов; `ofWeek`, `save` |
| `thanks.css` | Вид записей |

**Стыковка вне папки:** `screens/today/today.js` (карточка в «Отношениях», баллы), `sections/sections.js` (пункт
`thanks` в `ITEMS.rel`), `score/score.js` (часть `thanks`), тексты `us.thanks.*` и `sections.items.thanks` в
`js/texts/{woman,man}/{ru,ua,en}.js`, `index.html` (стиль), `files.js` (`npm run files`). Проверка —
`tests/thanks.test.js`.
