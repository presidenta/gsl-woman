# profile — профиль отношений

Решение владельца 14.11.2026: у обеих частей четыре версии программы, у каждой свои слова.

| Ключ | Женщина | Мужчина |
|---|---|---|
| `married` | Замужем (основной текст задания) | Жена (основной текст) |
| `together` | Живём вместе | Девушка, живём вместе |
| `dating` | Встречаемся | Девушка, встречаемся |
| `single` | В поиске — задания с мужчинами вокруг | В поиске — задания для женщин вокруг |

- Выбор — в настройках, карточка «Мои отношения» (`settings.profile`, синхронизируется вместе с настройками).
- Тексты — на сервере: у задания `variants` (`planner/server/src/woman/program/profiles-ru.js`, мужские — прямо в
  `src/men/program/ru.js`), у программы `profiles` — названия и подсказки. Пока только русский.
- `applyTask` подставляет слова профиля; вызывается в одном месте — `program/index.js` (`weekPlan`), поэтому
  экран, напоминания и записи сразу видят нужный текст.
- `showKids` — строка для детей (`task.kids`) видна у «жена / замужем» и «живём вместе» и только если дети добавлены в «Пять языков любви» → «Мои дети» (строки написаны про семью под одной крышей).
- `bizFor` — подсказка по делам недели (`week.biz`, у мужчин): день 1 — `start`, 2–5 — `daily`, 6 — `review`.
- В поиске — на «Сегодня» и в настройках ссылка на «Знакомство» (`../meet/`).
