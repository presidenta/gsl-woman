# GSL Woman+ для Android

Отдельное приложение (решение владельца 13.11.2026, путь «Б»): свой значок, потом свои виджеты и будильник.
Устроено точно как APK «Кванта» (`planner/.github/workflows/android-build.yml`): оболочка Capacitor 6 вокруг
сайта https://presidenta.github.io/gsl-woman/ — всё, что умеет сайт (вход, программа, работа без интернета),
приложение получает само, без пересборки. Пересборка нужна, только когда меняется родная часть.

| Что | Где |
|---|---|
| Название, адрес сайта, страница первого запуска без сети | `capacitor.config.json`, `www/index.html` |
| Значок (лотос, подложка #150c11) | `launcher-icon/mipmap-*` (из `assets/icons/icon-512.png` и `maskable-512.png`) |
| Сборка в облаке | закрытый `planner/.github/workflows/gsl-woman-android.yml` — Actions → «Сборка GSL Woman+ для Android» |
| Где взять готовое приложение | https://presidenta.github.io/quantum-diary/app/gsl-woman.apk (рядом с APK «Кванта») |

**Подпись.** Этот репозиторий открытый, поэтому ключа и сборки в нём НЕТ: они в закрытом `planner`
(`deploy/signing/gsl-woman.p12.base64`, рядом с ключом «Кванта»), — точно как у «Кванта». Сборка забирает
отсюда папку `android-app/`. Потерять ключ нельзя: обновление встаёт поверх только с той же подписью.
Правка здесь сама сборку не запускает — её запускают кнопкой в Actions репозитория planner.

**Родная часть** — `plugin/` (npm-пакет `gsl-native`, подключён в `package.json`): напоминания при закрытом
приложении (`GslScheduler`, будильники Android), будильник на весь экран (`GslAlarmActivity`), виджет
(`GslWidget`), после перезагрузки — `GslBootReceiver`; мост — `GslNativePlugin`. Веб-сторона — `../js/native/`.
Разрешения — в `plugin/android/src/main/AndroidManifest.xml` (Gradle подмешивает его в манифест приложения).
Рисунки виджета не переименовывать и не удалять без нужды: лаунчер помнит старые номера ресурсов (урок «Кванта»).
Программа для компьютера — по решению владельца пока не делается.
